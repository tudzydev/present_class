Feeling สถานการณ์ร้านสหกรณ์ฯ

เช้าวันแรกของงาน “ลดราคาต้นภาคเรียน” ป้ายระบบแสดงราคาสมุดโน้ต 45 บาท แต่พนักงานพาร์ทไทม์ที่รีบร้อน เปิดโค้ด Python แล้วแก้ตัวแปรราคาเป็น -500 เพื่อ “ให้ส่วนลดพิเศษ” ผลคือเครื่องคิดเงินทอนเงินผิดทั้งวัน สหกรณ์ฯ ขาดทุนโดยไม่มีใครตั้งใจให้เกิดขึ้นแม้แต่คนเดียว

1) คุณรู้สึกอย่างไรกับเหตุการณ์นี้ และกังวลเรื่องใดมากที่สุดหากคุณเป็นเจ้าของระบบ

2) ความผิดพลาดนี้เกิดจาก “คน” หรือ “การออกแบบ” มากกว่ากัน เพราะเหตุใด

เรื่องเล่าจากพี่เลี้ยง: “บรรทัดเดียวที่เปลี่ยนวิธีคิด”

พี่มิ้น — Senior Python Engineer เล่าว่าสมัยทำงานปีแรก เธอเขียนคลาสราคาแบบ “เปิดโล่ง” ให้ใครก็แก้ attribute ได้ วันหนึ่งสคริปต์รายงานของฝ่ายการตลาดเผลอไปแก้ราคาทั้งหมดเป็นศูนย์ ระบบหน้าร้านแสดงสินค้าฟรีทั้งวัน บริษัทเสียหายนับแสนบาท วันนั้นหัวหน้าไม่ได้ด่า แต่พูดว่า “อย่าออกแบบระบบที่พึ่งพาความระวังของคน จงออกแบบระบบที่ทำให้พลาดไม่ได้” ประโยคนั้นกลายเป็นหลักทำงานของเธอจนถึงทุกวันนี้

ถอดรหัสวิธีคิดของคนสำเร็จ:

  • ทำให้ “สถานะที่ผิด” เป็นไปไม่ได้ตั้งแต่ระดับการออกแบบ (Make illegal states unrepresentable)
  • ปกป้องกฎธุรกิจไว้ที่ขอบเขตของวัตถุ ด้วย property ที่ไม่มี setter
  • เขียนเทสกรณี “พัง” ก่อนกรณี “สำเร็จ” เสมอ

Finding Sandbox: ลองพังระบบดูสักครั้ง

ทัศนคติประจำใบงาน: Failure is learning — ผิดหรือถูกไม่สำคัญ นี่คือการทดลองเพื่อเติบโต

พิจารณาโค้ด “รุ่นเปราะบาง” ต่อไปนี้ แล้วทำนาย/ทดลองรันว่าเกิดอะไรขึ้น

class Product:
    def __init__(self, id: int, name: str, price: float):
        self.id = id
        self.name = name
        self.price = price   # ใครก็แก้ได้!

p = Product(1, 'สมุดโน้ต', 45.00)
p.price = -500   # ไม่มีอะไรทักท้วงเลย
print(p.price)

1) ผลลัพธ์คืออะไร และเหตุใดโค้ดภายนอกจึงแก้ราคาได้โดยไม่ถูกทักท้วง

2) หากต้องเลือก “จุดเดียว” ในคลาสเพื่อเฝ้าระวังราคา คุณจะเลือกจุดใด เพราะเหตุใด

3) ลองให้ AI เสนอวิธีป้องกันราคาติดลบใน Python มา 3 วิธี แล้วถกเถียงกับเพื่อน: วิธีใดน่าเชื่อถือที่สุด เพราะเหตุผลใด (AI เชื่อถือได้มากน้อยเพียงใด?)

📦 กล่องความรู้เสริม (อ่านเฉพาะเมื่อจำเป็น):
  • Encapsulation: รวมข้อมูล + เมธอดไว้ในที่เดียว และควบคุมการเข้าถึงจากภายนอก
  • Invariant: ความจริงที่ต้องเป็นจริงเสมอ เช่น price ≥ 0, ส่วนลด 0–100
  • Python: @property แบบไม่มี setter = อ่านได้แต่แก้โดยตรงไม่ได้
  • Convention: ชื่อขึ้นต้น _ สื่อว่า “ใช้ภายในคลาส” ไม่ควรเรียกจากภายนอก
  • Information Expert (GRASP): ใครมีข้อมูล คนนั้นควรรับผิดชอบพฤติกรรม

ส่วนที่ 1: อ่านแผนภาพแล้วตอบคำถาม (10 คะแนน)

1) สัญลักษณ์ (property) กำกับหลัง id, name, price หมายความว่าอย่างไรใน Python และแตกต่างจาก attribute ปกติอย่างไร 2 คะแนน

2) สัญลักษณ์ + และ - หน้าสมาชิกหมายถึงอะไร และการตั้งชื่อ _validate_price ด้วย underscore เดี่ยวสื่อความหมายตาม convention ของ Python ว่าอย่างไร 2 คะแนน

3) เหตุใด price จึงอ่านได้แต่ไม่สามารถกำหนดค่าจากภายนอกได้ ใช้กลไกใดของ Python 2 คะแนน

4) จงระบุ Invariant ของคลาส Product มา 2 ข้อ 2 คะแนน

5) ลูกศรที่กำกับว่า “raises” ชี้ไปยัง ValueError หมายความว่าอย่างไร และเกิดขึ้นเมื่อใด 1 คะแนน

6) เพราะเหตุใด Product จึงถือเป็น “Information Expert” ในการคำนวณราคาหลังลด 1 คะแนน

ส่วนที่ 2: วิเคราะห์โค้ด (10 คะแนน)

class Product:
    def __init__(self, product_id: int, name: str, price: float):
        self._id = product_id
        self._name = name
        self._price = self._validate_price(price)

    @property
    def id(self) -> int:
        return self._id

    @property
    def name(self) -> str:
        return self._name

    @property
    def price(self) -> float:
        return self._price

    def apply_discount(self, percent: float) -> None:
        if percent < 0 or percent > 100:
            raise ValueError("Discount must be between 0 and 100.")
        self._price = round(self._price * (100 - percent) / 100, 2)

    def display_price(self) -> str:
        return f"{self._name} (#{self._id}) ราคา: {self._price:.2f} บาท"

    def _validate_price(self, price: float) -> float:
        if price < 0:
            raise ValueError("Price cannot be negative.")
        return round(price, 2)

1) โค้ดบรรทัดใดป้องกันไม่ให้สร้างสินค้าที่มีราคาติดลบ 2 คะแนน

2) เมื่อเรียก Product(1, 'สมุดโน้ต', 45.00) แล้วเรียก apply_discount(10) ค่า price จะเป็นเท่าใด จงแสดงวิธีทำ 3 คะแนน

3) หากเรียก apply_discount(150) จะเกิดอะไรขึ้น เพราะโค้ดบรรทัดใด 3 คะแนน

4) หากภายนอกคลาสเขียนว่า product.price = -500 จะเกิดผลใด เพราะเหตุใด 2 คะแนน
